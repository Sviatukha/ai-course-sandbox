---
name: new-component
description: Create a new React component with tests and optional CSS. Create new component, add new component, создай компонент, добавить компонент
argument-hint: component name
---
1 - $0 - component name (if first letter is lowercase - it will be converted to uppercase). 
2 - Use src/components/Button and src/components/TextField as examples.
3 - Create a new folder in src/components with the component name
4 - Add a .tsx file, optional .css file, and a .test.tsx file
5 - Re-export the component in an index.ts file
6 - Cover the component with tests
7 - Run tests, lint, and typecheck after creating the component
